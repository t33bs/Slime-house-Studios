# v32 — Eyedropper (I)

Press **I** to activate the Eyedropper, or choose it from the tool dropdown. Click any nontransparent pixel on the canvas to sample its displayed RGBA color, then return automatically to the previously active drawing tool. Transparent pixels leave the color unchanged. No layer is edited and no undo checkpoint is added. Works with regular Pencil and Frame Pencil because both use the same paint color.

Testing: source compilation and automated pytest suite; Windows GUI runtime remains to be verified.
