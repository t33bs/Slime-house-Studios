# v42 Creature Rig & Sprite Sheet Builder (Phase 3)

Open Desktop Pet Builder → Create • Step by Step → Open Creature Rig & Sprite Sheet Builder.

- Import multiple transparent PNG parts; change their layer order by import order.
- Position parts using pixel-exact X/Y controls.
- Save pose frames under editable animation names; create multiple animation sequences.
- Save and reopen an editable rig project (.json + accompanying part PNG directory).
- Export a transparent grid PNG sprite sheet plus JSON frame rectangles and animation labels.

Limitations: drag handles, rotation, pivot joints, automatic in-betweening, importing existing sprite sheets, and playback in this new dialog remain future work. Existing pet wizard and animation studios remain unchanged.
