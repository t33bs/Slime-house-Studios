# v53 — Blink color and movable Laser Eyes emitter

- Blink eyelid line now uses the selected animation region color. Choose a color from the existing Effect Color palette or Custom color.
- Junior Animator has an **Add movable Laser Eyes** button. It creates a 1-pixel non-destructive emitter region centered on the canvas and selects the **Move Laser Asset** tool. Drag on the canvas to position it; change beam color, length, and direction using existing region controls.
- The asset is saved with the project's animation regions and supports undo. This is an animated region emitter, not a separate PNG artwork layer; two eyes require two emitters.
- Windows UI and real export verification still required.
